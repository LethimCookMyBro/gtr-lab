# Centered exhibition preview · 5 October 2026

Bounded refinement of the existing homepage, prepared for visual review. This candidate is not authorization to release it publicly.

## Design

- Archive: four factual years (1969, 1989, 1999, 2007), centered masked slots, narrative at the horizontal center, three silver-framed photographs per era. Original captions and all 12 direct credits are preserved. Photographs use contain, never crop a race car.
- Desktop: native sticky exhibition, competition → road → engineering entrance, a reading hold, and geometry-driven reversal. No artificial counter years.
- Phones: year and narrative first, then three photographs in document flow. Short and reduced-motion views keep natural-flow access and the keyboard era index.
- Rear: same licensed Ciasny custom-aero R35 exterior, larger desktop camera framing, real lamp emission first, scroll-bound white studio pass, stable cubemap/contact shadow resources, smaller authentic marks. No claim of OEM geometry.
- Loader: one chrome pass and red-image reveal, authentic source proportions. Progress still reports real model bytes, decode/preparation and render readiness. Skip, retry and Save-Data remain available.
- Sound: optional separate listening band. The original 7.6-second R35 SpecV recording starts only from Hear. User mute, loading cancellation, hidden-tab cancellation and route/unmount cleanup are covered. See ../R35_AUDIO_PREVIEW.md for source and license details.

## Review evidence

GitHub Actions records actual browser input, production assets, readiness, canvas and navigation at 1440×900, 1920×1080, 390×844, 430×932 and 1440×600. The viewport-native recordings are silent: they do not certify speaker output. The original audio is provided separately, without synchronization to the visual scene.

CI uses SwiftShader, not a physical mobile GPU. No physical-device performance claim. External NissanNews/Flixel playback remains a separate acceptance scope; this refinement does not replace, crop or modify provider films.

Inspection is bounded to one combined desktop/mobile review, a single issue-fix batch, then confirmation.
