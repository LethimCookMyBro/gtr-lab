# Detailed-interior GT-R model acquisition review

Checked 2026-10-01. Status: **no production-qualified, detailed-interior R35 GLB acquired**. No model from this review was put in the public application directory. Photographs and CC0 environments remain separately cleared in their existing credits.

The requirement is a human-created, realistic R35 exterior and detailed cabin, with rights to convert/optimize it and deliver it as a browser-fetched GLB/glTF in GT-R LAB. A marketplace's “free,” “royalty free,” or “web apps” label alone does not establish that the underlying model may be exposed as a public GLB. This record is an acquisition assessment, not legal advice.

Source repository: https://github.com/SagarTayde13/Nissan_gtr_Showcase

Public file: https://raw.githubusercontent.com/SagarTayde13/Nissan_gtr_Showcase/main/public/models/nissan3d.glb

- Payload: 5,102,116 bytes; valid GLB 2.0, 53 meshes and 50,391 triangles
- SHA-256: `b1dab237706cbcd69e52d6383cad62ad40d9d1335ce47329dc41b97a68550588`
- Embedded metadata credits **jakob.kush367 / Red**, CC BY 4.0, https://sketchfab.com/3d-models/nissan-gt-r-29516e2e739c44b8a6edf2ca87d780d7
- That Sketchfab page also displays CC Attribution and publication date 2022-04-23, but only describes the model as “nissan gtr”; original creation is not established
- Blender import and local exterior render succeeded. It is genuine R35-style geometry, not a primitive placeholder. Detailed interior was not qualified
- **Five embedded texture images match decoded RGB pixels exactly** against the GT-R texture set in https://github.com/stephengold/jme-vehicles/tree/master/MavCommon/src/main/resources/Models/gtr_nismo/textures
- Matching files: `tyre_baseColor.png`, `tyre_normal.png`, `sidewal_baseColor.png`, `sidewal_normal.png`, and `Material.010_baseColor.png`
- The older repository expressly attributes its GT-R to **iSteven**, CC BY-NC-SA 4.0: https://github.com/stephengold/jme-vehicles#cc-attribution
- iSteven's current original listing displays CC BY-NC and credits **D3NK**: https://sketchfab.com/3d-models/nissan-gt-r-5f5781614c6f4ff4b7cb1d3cff9d931c
- D3NK's related 2017 R35 Warehouse listing explicitly says it was converted from CSR Racing 2: https://embed-3dwarehouse-classic.sketchup.com/model/9b5b874d-76cf-4816-a7ee-828623d7bb57/2017-Nissan-GTR-R35

The matching textures establish reused material and an unresolved licensing chain; they do not by themselves prove that every vertex comes from the same source. This is enough to withhold it from deployment rather than accept the newer CC BY label at face value. Inspection files stay outside the repository at `/tmp/gtr-red-candidate.glb` and `/tmp/gtr-red-inspection.blend`.

Also inspected: `HadiKachmar/NISSAN-GTR` contains a GLTF and CC BY label for an Allay Design model named **NFS Most Wanted Razor Version**. Original rights remain unverified, so it was not deployed. `Sarthak-075/nissan-gtr-showcase` has no portable model found in its current tree and its README reserves third-party asset ownership rather than granting rights.

## Exact acquisition requirement to clear

Before payment or deployment, obtain a written grant that covers:

1. The named model, source geometry and textures, with confirmation of original authorship or authorized third-party sources
2. GT-R LAB's intended public interactive automotive showcase/configurator use
3. Conversion to GLB/glTF, mesh optimization, compression, material changes, paint and wheel customization
4. Hosting the processed asset on the application's public server/CDN so browsers fetch it for Three.js rendering, acknowledging that browser-delivered model bytes are technically retrievable
5. Any permitted source-repository distribution, separately from runtime delivery; do not commit stock source assets to a public GitHub repository unless expressly allowed
6. Attribution, model-year/trim limitations, editorial/trademark restrictions, number of projects, audience limits and final total

Ask for representative cabin renders or a permitted sample showing steering wheel, instruments, center console, seats, door cards and back seats. Validate the supplied file and performance before representing a detailed interior as complete.
