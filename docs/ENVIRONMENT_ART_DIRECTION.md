# Real-geometry environment direction

This is an original configurator venue design. No reference photograph below is
rehosted or used as scenery, a texture or a backdrop.

## Observed real-location references

- Porsche development workshop, Weissach (Porsche's original 2021 photography):
  https://newsroom.porsche.com/en/2021/company/porsche-development-centre-weissach-christophorus-397-23162.html
  Observed compact working scale, neutral grey surfaces, formed steel sections,
  substantial door surrounds, suspended linear luminaires and restrained task lighting.
- Showroom Eurobike / SAINZ arquitetura, built 2014, photographed by Cesar Edgard:
  https://www.archdaily.com/521578/showroom-eurobike-porsche-1-1-arquitetura-design
  Reference for clear display space, glass, clean concrete and differentiated architectural lighting.
- Hayami–Uki coastal road, Nagasaki, National Film Archive of Japan location database:
  https://jl-db.nfaj.go.jp/location/420111540/
  March 2019 photograph inspected for actual two-lane width, shoulder and drainage
  hierarchy, formed guardrail/retaining construction, curve, blue sea and horizon.

## Application

The pit is a compact original workshop with I-section columns, base/connection
plates, raised door frames, formed shutters, tool storage and suspended framed
luminaires. Neutralized scanned concrete retains photographed surface variation.
The gallery has a distinct curved plaster wall, round columns, glass frontage and
an open daylight ring, with no garage doors or pit markings. After-hours uses the
same real workshop with local ceiling light pools and reduced daylight.

The test paddock uses a five-bay pit building and real lane/parking/curb structure.
The coastal pull-off bends into the distance with a narrower marked road, an
engineered shoulder and supporting sea wall. Sea lies behind the default hero
view; low distant terrain replaces the first rejected faceted hill ramp. Actual
CC0 rock scans supply nearby irregular silhouettes. The sky is an unprojected, partly-cloudy real sky-only HDR. The water surface uses a static original multi-scale wave normal field, Fresnel and a live planar reflection of the real scene, not a photograph masquerading as geometry.

The camera now has an 11m clear envelope, with portrait field-of-view compensation
so rooms can have credible scale. Far clip remains sufficient for the true sea
horizon. Top is a cutaway/open-atrium inspection view rather than a cabin view.
