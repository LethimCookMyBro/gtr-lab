# Remaining authentic variant assets

Research checkpoint: 2026-10-01. None of the candidates below has been purchased, downloaded for use, or cleared for this project's publicly fetched GLB delivery. Store prices are observed listings, not a quote including taxes. A store license is not evidence that a re-uploader owns a game mesh.

The six-vehicle requirement remains open. The integrated Ciasny exterior is a custom-aero R35 with unverified exact trim/year. It is not a substitute for five separately shaped models. Both the early original exterior and the later newly authored cabin studies were rejected; neither rejected geometry is included in the app or any published commit.

[CGTrader's terms§21A.2–3](https://www.cgtrader.com/pages/terms-and-conditions) permit incorporated applications with extraction safeguards. That is not a blanket ban on websites. This project currently serves a standard GLB that is technically retrievable, and its public GitHub repository also contains reconstructable asset chunks. Public distribution of those raw assets is broader than incorporated web-app use. Do not place a paid/raw model in the public repository merely because a license allows app use. Obtain appropriate public-source redistribution rights, or keep asset sources private and design delivery safeguards consistent with the actual license. Separately confirm optimization/adaptation and original geometry/texture ownership. No seller has been contacted or asked to enter an agreement.

## Next acceptance steps

Obtain a licensed original asset or an explicitly authorized modification of a compatible base; visually verify the variant-specific exterior, cabin and material separation; preserve source provenance; optimize without concealing weak geometry; and test the actual file in the application. Show any newly authored interior preview for approval before integrating it. Do not color-change or relabel the same car six times.
