# Environment scope and quality limits

These are original, real-geometry configurator venues, with licensed scanned
materials and ground relief. They are not photogrammetric recreations of the
reference locations and are not presented as premium photoreal imagery.

- Architecture and outdoor layouts remain deliberately sparse. Repeated surface
  tiles, modular structures and a synthetic lighting character can still be
  apparent, particularly in distant scenery and wide views.
- Vehicle reflections use a local environment capture. The sea uses a bounded
  planar reflection and a static, original irregular wave-normal field. These
  are real-time approximations, not full light transport, weather or ocean
  simulation. The sea reflection target defaults to 256 pixels per side.
- High exterior inspection views intentionally cut away overhead room fixtures
  and roof elements to keep the camera clear. This is an inspection treatment,
  not an interior/cabin feature.
- Only the existing licensed Ciasny custom-aero R35 exterior has interactive
  geometry. The other five variants remain clearly labelled photographic
  references, and a detailed cabin is not supplied by this asset. Vehicle
  geometry was not changed for this environment replacement.
- Automated rendered evidence uses Chromium with ANGLE SwiftShader on GitHub
  runners, including 390×844, 1440×900 and 1920×1080 viewports. It does not
  establish hardware-GPU frame rates or physical-phone performance. Capturing a
  view or passing interaction tests is not a claim of artistic acceptance.
